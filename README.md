## 📱 Hướng Dẫn Cài Đặt Chi Tiết Trên iPhone

1. **Thêm Module vào Shadowrocket**:
   - Mở app **Shadowrocket** -> chọn tab **Cấu hình (Config)**.
   - Chọn mục **Mô-đun (Modules)** -> chọn **Thêm mô-đun (Add Module)**.
   - Dán liên kết `https://raw.githubusercontent.com/dth20006/shadow/main/dth.sgmodule` vào rồi nhấn **Tải về / Xong**.
2. **Cài Đặt Chứng Chỉ HTTPS Decryption**:
   - Vào **Cài đặt (Settings)** trong Shadowrocket -> **Chứng chỉ (Certificate)** -> Tạo chứng chỉ CA mới (nếu chưa có).
   - Chọn **Cài đặt chứng chỉ vào hệ thống**.
   - Mở **Cài đặt máy (iOS Settings)** -> **Đã tải về hồ sơ** -> bấm **Cài đặt**.
   - Vào **Cài đặt chung (General)** -> **Giới thiệu (About)** -> kéo xuống dưới cùng chọn **Cài đặt tin cậy chứng nhận (Certificate Trust Settings)** -> **BẬT tin cậy đầy đủ** cho chứng chỉ Shadowrocket.
3. **Bật VPN**:
   - Quay lại Shadowrocket, bật công tắc kết nối VPN (nút tròn màu vàng/xanh ở màn hình chính).
4. **Kích Hoạt Locket**:
   - Vuốt từ dưới màn hình lên mở App Switcher, **vuốt tắt hẳn (Force Close) app Locket**.
   - Mở lại Locket: Tận hưởng Locket Gold vĩnh viễn, nhấn giữ để quay video 60s và vuốt chọn 280+ Caption VIP!
