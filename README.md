**Để kích hoạt ngay lập tức:**
1. Cài đặt / Cập nhật module `dth.sgmodule` trong Shadowrocket.
2. Đảm bảo **HTTPS Decryption (MITM)** đã bật và Root Certificate đã được tin cậy trong Cài đặt iOS.
3. Bật kết nối VPN Shadowrocket.
4. **Vuốt tắt hẳn (Force Close)** ứng dụng Locket từ màn hình đa nhiệm (App Switcher).
5. Mở lại Locket -> Chụp một bức ảnh:
   - **Xem Caption**: Chạm vào ô nhập chú thích / vuốt thanh caption để chọn các danh mục Tiêu đề tiếng Việt.
